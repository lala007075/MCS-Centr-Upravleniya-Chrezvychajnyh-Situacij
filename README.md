# ЦУЧС ГУ МЧС России по ЦАО г. Москвы

Автоматизированная система регистрации и мониторинга вызовов
Центра управления в чрезвычайных ситуациях.

## Экстренные телефоны
- 101 — Пожарная охрана и спасатели
- 112 — Единый номер экстренных служб

## Технологии
- Backend: Node.js + Express
- База данных: PostgreSQL (Neon)
- Хостинг: Render

## Запуск
npm install
npm start
